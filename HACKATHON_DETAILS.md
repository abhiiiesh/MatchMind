## 🎯 The Challenge

**Build AI-driven applications and agents that transform synthetic football (Premier League) events into explainable match intelligence.**

Projects should:
- Surface meaningful stats & identify key moments
- Explain *why* they matter (not just *that* they happened)
- Generate personalized experiences for different audiences

### Required 5-Stage Pipeline

| Stage | What to do |
|---|---|
| **1. Ingest** | Synthetic match events in real-time (passes, shots, tackles, possession changes, pressure events, metadata) |
| **2. Interpret** | Aggregate into meaningful football statistics, patterns, and context |
| **3. Explain** | Provide explainability — why a moment matters (tactical pressure changes, game rhythm, control vs. chaos) |
| **4. Render** | Produce outputs that can sit on-screen alongside a live match (overlays, graphics) |
| **5. Personalize** | Tailor experiences for data-hungry analysts AND casual fans (language, favorite club/player, viewing modes) |

### Additional Feature Areas
- **Player identification** — real-time name tagging, speed/distance indicators
- **Pass quality** — distance, accuracy, difficulty rating
- **Speed metrics** — ball speed, shot speed
- **Auto-eventing** — ML model over video feed to auto-generate metrics
- **Narrative generation** — key narratives, player-performance context, milestones, match recaps
- **Data innovation** — create/extend synthetic football datasets
- **Multi-language storytelling** — natural-language outputs for global scenarios

## ✅ Can We Use Gen-AI and Agentic Tools?

### 🟢 YES — Gen-AI and Agentic Tools Are ENCOURAGED

Based on the official rules and challenge description:

1. **The hackathon explicitly asks for "AI-driven applications and agents"** — the entire challenge revolves around building AI-powered solutions.

2. **"Best Multi-Agent System Prize"** is a dedicated category prize for multi-agent collaboration using:
   - **GitHub Copilot**
   - **Microsoft Agent Framework**
   - **A2A (Agent-to-Agent)**
   - Or any other supported orchestration approach

3. **Resource playlists** include training on:
   - GitHub Copilot (coding acceleration)
   - Azure AI Foundry (building AI apps)
   - Agentic workflows

4. **Your project can take the form of:** an AI agent, workflow, integration, data platform, analytics experience, automation solution, or an entirely new experience.

5. **Third-party integrations are allowed** as long as you are authorized to use them per their licensing terms.

> **Bottom line:** Using Gen-AI, LLMs, agentic tools, GitHub Copilot, Azure AI, and multi-agent frameworks is not just allowed — it's the *core expectation* of this hackathon.
